# Sarysu — GitHub Pages + Google Sheets

Сайт работает как обычные HTML/JS-файлы на GitHub Pages. Запуск Node.js, установка npm-пакетов и отдельный сервер не нужны. Чтение и запись выполняет Google Apps Script в аккаунте владельца таблицы.

jQuery не требуется: он не предоставляет права записи в Google Sheets. Ссылка `/edit` открывает редактор таблицы; для автоматического сохранения ответов нужен адрес опубликованного Apps Script `/exec`.

## Однократная настройка Google

1. Откройте [вашу таблицу](https://docs.google.com/spreadsheets/d/1-11ekWroxvJjHRIPpp6v_IprH0RnygjMQ_BCNMq5tNo/edit?gid=0) → **Расширения → Apps Script**.
2. Замените содержимое `Code.gs` полным содержимым файла `google-apps-script/Code.gs` из этого проекта. ID таблицы и лист `gid=0` уже настроены.
3. Сохраните. Выберите функцию **setup**, нажмите **Выполнить** и разрешите доступ к таблице. Если лист пустой, появятся заголовки и 116 демонстрационных анкет с `source=demo`. Непустой лист другой структуры не будет перезаписан.
4. Нажмите **Развернуть → Новое развертывание → Веб-приложение**. Настройки:
   - Выполнять от имени: **Я** (владелец таблицы).
   - Кто имеет доступ: **Все / Anyone**, включая пользователей без входа в Google.
5. Нажмите **Развернуть**, скопируйте URL вида `https://script.google.com/macros/s/…/exec`.
6. Вставьте URL в `config.js`:

   ```js
   window.SARYSU_CONFIG = {
     appsScriptUrl: 'https://script.google.com/macros/s/ВАШ_ID/exec'
   };
   ```

7. Опубликуйте изменения в ветку `main`. GitHub Actions загрузит на Pages только `index.html`, `results.html`, `survey-results.js` и `config.js`.

Если политика рабочего/учебного Google-аккаунта запрещает доступ «Все», анонимная форма не заработает — нужен аккаунт, в котором разрешено такое развертывание. После изменений в `Code.gs` обновляйте развертывание через **Управление развертываниями → Изменить → Новая версия**.

Таблицу не требуется открывать всем на редактирование. Сервисный аккаунт, JSON-ключи и `.env` для этой версии не используются. `config.js` содержит только публичный URL, не секреты.

[Официальная инструкция Google по развертыванию](https://developers.google.com/apps-script/guides/web). Apps Script работает в инфраструктуре Google; для этой схемы отдельный платный хостинг не нужен, действуют [квоты Apps Script](https://developers.google.com/apps-script/guides/services/quotas).

## Как это работает

- При первом обращении пустой лист получает 116 демонстрационных анкет. Их происхождение явно отмечено в таблице и на сайте.
- Новые заполнения записываются как `source=submitted`. Результаты берутся только из таблицы; повторного прибавления 116 в браузере нет.
- После POST сайт проверяет в таблице ID записи. Только найденная запись считается успешно сохранённой; непрозрачный ответ браузерного запроса сам по себе не является подтверждением.
- Повторная отправка той же анкеты после сетевого сбоя использует тот же ID. Блокировка Apps Script защищает от одновременного добавления дублей и повторного начального заполнения. Используйте один Apps Script-проект для этой таблицы.
- Сразу после отправки обновляются счётчик и проценты. Другие посетители получают обновление при возвращении на страницу или примерно через 30 секунд.
- Предложения хранятся как JSON-текст в `suggestion_json`, не исполняются как формулы и не показываются в публичных результатах. Имена не запрашиваются. Публичное чтение возвращает только анонимные варианты ответов.
- Старые ответы из localStorage не переносятся автоматически. Если Google недоступен, форма не выдаёт локальное сохранение за запись в таблицу.

## Проверка подключения

Откройте URL `/exec` в приватном окне: должен появиться JSON с `"ok":true`, массивом `rows` и `demoCount`. Затем откройте сайт, отправьте анкету и убедитесь, что появилась строка `submitted`, а счёт вырос с 116 до 117. Если URL ведёт на страницу входа, проверьте доступ **Все / Anyone**.

Автоматические проверки логики находятся в `tests/apps-script.test.cjs`. Разработчик может запустить их командой `node --test tests/apps-script.test.cjs`; для работы и публикации самого сайта Node.js не используется. Проверки используют имитацию Google Sheets и не заменяют проверку реального развертывания.
